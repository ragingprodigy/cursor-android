# Cursor Android

Flutter Android app scaffold for remotely controlling Cursor Cloud Agents.

## Development

This project is generated for Android only with package/application ID:

```text
io.haxl.cursor
```

Common checks:

```bash
flutter analyze
flutter test
```

## Structure

- `lib/app/` - app shell and routing entry points
- `lib/core/` - shared infrastructure
- `lib/features/` - feature modules
